# PAPER-04 diff summary

PAPER-04 changes are limited to the durable tool timeline/history and its tests:

- Edge: `cloudflare-worker/src/sessions.ts` now authorizes the session first, derives text from canonical `chat_events`, emits a collapsed per-tool history response, caps text/arguments/results, redacts sensitive argument keys, and omits object keys and raw payload fields. Legacy `chat_messages` history remains readable and is explicitly labeled.
- Edge SSE: `cloudflare-worker/src/chat.ts` now emits correlated status, `tool_call`, and `tool_result` events with bounded/redacted display summaries; provider-facing persistence remains in the PAPER-03 canonical ledger.
- Frontend API/state: `frontend/lib/api/sessions.ts` and `frontend/lib/chat-state.ts` add bounded history normalization, foreign-session filtering, per-session timeline hydration, legacy labeling, and call/result collapse/update actions.
- Frontend stream/controller/UI: `frontend/lib/ws/chat-stream.ts`, `frontend/hooks/use-chat-controller.ts`, `frontend/components/chat/ChatWorkspace.tsx`, and `frontend/components/chat/MessagePane.tsx` parse safe correlated events, retain live status, hydrate after reload, and render expandable tool rows.
- Tests: added/updated Edge session/chat tests, frontend stream/session/state tests, and `frontend/e2e/chat.spec.ts` coverage for live calls, result transitions, reload restoration, malformed/foreign/long payloads, legacy history, and task confirmation cancellation.

The working tree also contains retained PAPER-01 through PAPER-03 changes and evidence. The user-provided design/plan documents remain untracked and were not modified.
