# PAPER-05 diff summary

PAPER-05 adds the authorized paper-resource metadata/object boundary:

- `cloudflare-worker/migrations-infinity/0018_paper_resources.sql` adds additive, bounded D1 tables for resources, processing attempts, and session-purpose links with foreign keys, indexes, state checks, lease-hash/fencing fields, and no destructive operation.
- `cloudflare-worker/src/db.ts` adds typed resource/attempt/link rows, ownership-aware link/read/revoke helpers, attempt metadata, and conditional state transitions fenced by active attempt, lease expiry, and fencing epoch. The legacy `paper_authorizations` table remains compatibility-only.
- `cloudflare-worker/src/paper-object-store.ts` is a narrow fixed-kind R2 getter with no list/prefix or caller-supplied key capability.
- `cloudflare-worker/src/paper-resources.ts` adds authenticated create/read/delete/link routes, safe metadata responses, ready-only manifest/object reads, fixed object selection, manifest sanitization, bounded inputs, and ownership/link validation.
- `cloudflare-worker/src/index.ts` composes the resource routes inside the existing authenticated/CSRF API boundary.
- `cloudflare-worker/test/fake-d1.ts`, `test/d1-runtime-schema.test.ts`, and `test/paper-resources.test.ts` provide deterministic D1/R2-shaped coverage for positive and negative cases.

Retained prior-card changes are present in the same working tree and were not reverted. No external system was modified.
