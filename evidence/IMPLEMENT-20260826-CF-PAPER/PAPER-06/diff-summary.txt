# PAPER-06 diff summary

PAPER-06 adds the dedicated Paper Processor control plane while preserving the public Worker-v2 boundary:

- `cloudflare-worker/migrations-infinity/0019_paper_processor_sessions.sql` adds hash-only short-lived Processor sessions and partial unique indexes enforcing at most one active attempt per resource and per Processor identity.
- `cloudflare-worker/src/db.ts` adds session authentication, one-resource claim, lease renewal, ordered stage transitions, fixed-kind object recording, finalize-once, and fenced cancellation helpers. All mutations are conditional on exact resource, attempt, Processor identity, lease hash, fencing epoch, active status, and lease expiry.
- `cloudflare-worker/src/paper-processor.ts` adds fixed connect/poll/input/renew/stage/object/finalize/cancel routes. Responses never expose R2 keys, parent credentials, or arbitrary caller-selected object paths; uploads are bounded and checksum verified.
- `cloudflare-worker/src/paper-object-store.ts` adds fixed server-owned `source_pdf`, `text_manifest`, and `image_manifest` put access alongside the existing fixed getter.
- `cloudflare-worker/src/index.ts` routes the dedicated control plane before browser-cookie/CSRF API handling and leaves `/api/worker/v2/` unchanged.
- `backend/paper_processor/{__init__.py,client.py,runner.py}` and `backend/Dockerfile.paper-processor` provide a protocol-only, non-root dedicated image scaffold. It does not import or install public Worker, database, object-store, relay, or model runtime dependencies; PDF admission/extraction remains for PAPER-07 onward.
- `cloudflare-worker/test/fake-d1.ts`, `test/paper-processor.test.ts`, `test/paper-processor-schema.test.ts`, `test/paper-processor-image.test.ts`, and `test/index.test.ts` provide positive and negative control-plane evidence.

Retained prior-card changes are present in the same working tree and were not reverted. No external system was modified.
