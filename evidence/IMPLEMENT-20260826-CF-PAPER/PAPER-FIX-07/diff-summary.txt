# PAPER-FIX-07 diff summary

## Runtime changes

- `backend/paper_processor/ingest.py`
  - Adds non-secret attempt/stage runtime limits: 240s whole attempt, 90s
    download, 120s extraction, 90s upload/finalize, 30s lease heartbeat, and
    192 MiB resident-memory budget.
  - Adds monotonic deadline checkpoints, a Unix wall-clock alarm for a stuck
    synchronous parser, RSS checks, background fenced-lease renewal, bounded
    terminal failure codes, and temporary-workspace cleanup.
  - Calls the existing `fail` operation for timeout/memory/heartbeat failures;
    unexpected runtime failures remain safe cancellation. Logs expose only
    opaque resource/attempt IDs, stage, and safe error code.
- `backend/paper_processor/runner.py`
  - Loads the non-secret limits, configures visible safe INFO logging, emits
    bounded lifecycle diagnostics, and reconnects after a terminal attempt
    outcome without exposing exception details.
- `backend/paper_processor/infinity-paper-processor.service`
  - Declares the fixed non-secret limits, `MemoryHigh=192M`,
    `MemoryMax=256M`, `KillMode=control-group`, and retains one user-systemd
    `ExecStart` with the existing hardening.
- `backend/paper_processor/delivery.v1.json`
  - Records the limits, failure codes, service constraints, and synchronized
    source/service/dependency hashes.
